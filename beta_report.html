How this was counted

  • Generated once from a copy of the beta database taken 2026-10-20. It will not change.
  • A client patch on 23 Sep briefly dropped surnames, so eight characters logged under two names. They are counted as one: Kaede → Kaede Windjammer, Norrin → Norrin Dawnstone, Port → Port Vehx, Ozzman → Ozzman Goeth, Cyklades → Cyklades Usa, Bank → Bank Ofozzman, Ytzw → Ytzw Ww, Ytzm → Ytzm Zz.
  • Test and one-session names were left out: Cyk Bufftester, Test, Test Afasdfae, Thanatu Mournveil, Volice Korvino, Ytz Zz.
  • Quests are the ones this dashboard saw turned in. The game's own lifetime count includes play from before the beta.
  • Gold is shared by choice, so the gold award only ranks those sharing. AFK time is measured by the addon and only since it was installed.
  • Times are US Eastern. Level timings use the in-game clock on each event; the first 184 events of the beta predate that and are not timed.
