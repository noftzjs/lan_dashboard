4L Setup

Dashboard Analytics Roster Setup

Get your characters on the leaderboard

Two small pieces run on your PC: an addon inside WoW that records your progress, and the watcher, a tray program that sends it here. Three steps, about five minutes.

1

Install the addon

Download the addon LanDashboard.zip
  1. Unzip it. You get a folder named LanDashboard.
  2. Copy that folder into your WoW AddOns folder: C:\Program Files (x86)\World of Warcraft\_classic_era_\Interface\AddOns\ Use whichever version folder your install has, such as _classic_era_ or _classic_beta_.
  3. Start WoW. On the character screen, open AddOns and make sure LAN Dashboard Data Streamer is ticked. If it says out of date, tick Load out of date AddOns.
2

Log in and sync

  1. Log in to your character. This button appears at the top of the screen: Click it. Your UI reloads, and that is what saves your progress to disk.
  2. Click it whenever it comes back, after a few quests or a level-up. Logging out saves everything too.
3

Start the watcher

  1. Enter the passphrase you were given and download the watcher. It comes as a zip with its settings already inside.
    Download the watcher
  2. Unzip it anywhere (right-click, Extract All). You get a LanDashboardWatcher folder; keep it together and double-click savedvars_watcher.exe inside it.
Download the watcher savedvars_watcher.exe · Windows
  1. Put savedvars_watcher.exe in a folder of its own, for example Documents\LanDashboard Watcher.
  2. Download its settings file below into that same folder, keeping the name savedvars_watcher_config.json.
    Your settings file

    Server address:

    This dashboard needs an access token. Paste the one you were given; it is only written into the file you download.

  3. Double-click savedvars_watcher.exe.

The watcher isn't available on this server yet. Ask whoever runs it.

Windows will say "Windows protected your PC" the first time. Choose More info, then Run anyway.

No window opens. A gold 4L icon appears in the tray by the clock (under the ^ arrow if you don't see it). A green dot means it's working, and your character is on the dashboard within a few seconds. From now on it starts with Windows, so you can forget about it.

⚙

Optional: choose what you share

Type /ldb in game to see everything the dashboard may show about you: gold, item level and AFK time. Untick anything you'd rather keep to yourself. A hidden value is never sent at all; the dashboard just shows a dash. Changes apply at your next sync.
